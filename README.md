# 基于STM32的智能温控风扇系统 (Smart Temperature Control Fan)

##  项目简介
本项目是一个软硬结合的机电一体化原型系统。采用 STM32F103C8T6 作为主控，通过 DS18B20 实时采集环境温度，使用 OLED 屏幕显示温度与风扇状态，并通过 PWM 信号驱动 MOS 管模块，实现对 12V 直流风扇的无级调速。项目从面包板原型验证起步，最终完成了洞洞板的硬件固化，具备较高的稳定性。

##  功能特性
- **实时温度采集**：使用 DS18B20 单总线传感器，精度 0.1℃。
- **智能滞回控制**：防止温度在临界点频繁启停风扇。
  - 当温度 > 30℃ 时，风扇全速运转 (100% 占空比)。
  - 当温度 < 28℃ 时，风扇停转 (0% 占空比)。
  - 当温度在 28℃ ~ 30℃ 之间时，根据温差进行线性调速。
- **状态可视化**：0.96寸 I2C OLED 屏幕实时显示当前温度及风扇状态 (FULL/OFF/AUTO)。
- **硬件固化**：纯手工飞线焊接至洞洞板，模块采用排母插拔式设计，便于后期维护。

##  核心踩坑与解决方案记录 (Debug Log)
*这是本项目最有价值的部分，记录了开发过程中排查的硬件与软件Bug：*

1. **MOS管驱动选型问题**：初期使用 IRF520 模块，发现 STM32 的 3.3V 逻辑电平无法使其完全导通，风扇无法转动。后更换为支持 3.3V 逻辑的 **D4184 模块**，问题解决。
2. **DS18B20 时序与死锁**：起初读取温度乱码或一直显示 -0.1℃。排查发现单片机发送转换命令 `0x44` 后，未等待传感器转换完成就进行了复位操作。**解决**：在 `DS18B20_Start()` 后加入 `delay_ms(800)` 延时。
3. **极其隐蔽的上拉电阻选型错误**：在洞洞板焊接完成后，温度死锁 -1000℃。经万用表排查，误将 **4.7Ω** 电阻当作 **4.7KΩ** 上拉电阻使用，导致数据总线被死死拉高，单片机无法拉低总线发送复位脉冲。更换正确电阻后完美解决。
4. **洞洞板焊接短路**：手工飞线交叉时，因焊锡过多导致相邻孔位短路。通过万用表蜂鸣档排查，清理连锡后系统稳定。
